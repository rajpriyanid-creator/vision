## Brand & Style

The design system projects high-order cognitive clarity, executive discipline, and surgical intelligence. Tailored for deep technical study, advanced problem-solving, and spatial retention, the aesthetic mirrors an elite aerospace command interface or an advanced quantum compute terminal. 

The aesthetic style merges **Technical Glassmorphism** with **Deep Luminous Obsidian Minimalist Architecture**:
- Surfaces do not emulate generic flat design; they leverage deep layered midnight substrates infused with faint blue-violet electromagnetic radiance.
- Information density is deliberate, compact, and hyper-structured, avoiding visual clutter while facilitating high-velocity comprehension.
- Razor-thin light guides and frosted semi-conductive structural dividers delineate cognitive modules, creating an atmosphere of clinical precision and intellectual supremacy.

## Colors

The palette operates on a four-tier obsidian elevation model illuminated by tactical cognitive accents:

- **Surface Tiers**:
  - `Base / Canvas`: `#090D16` (Deep obsidian substrate)
  - `Layer 1 / Panels`: `#0D1322` (Midnight graphite foundation)
  - `Layer 2 / Interactive Containers`: `#131B2E` (Suspended modules)
  - `Layer 3 / Overlays & Popovers`: `#1A243B` (Elevated telemetry layers)
- **Primary Intelligence Spectrum**:
  - Electric Cyan (`#00D2FF`) for computational focus, focal indicators, and active execution pathways.
  - Azure Mist (`#38BDF8`) for secondary analytical highlights and telemetry readouts.
  - Deep Azure (`#0284C7`) for pressed states, tracks, and structural containment borders.
- **Cognitive Diagnostics**:
  - **Mastery Emerald**: `#10B981` (Glow: `#34D399`) marks validated retention, solid execution, and verified nodes.
  - **Hypothesis Amber**: `#F59E0B` indicates probabilistic models, review thresholds, and diagnostic testing states.
  - **Dependency Crimson**: `#F43F5E` flags prerequisite blockers, conceptual breakdown, and systemic decay.
- **Micro-Gradients & Ghost Boundaries**:
  - Standard structural border: `rgba(99, 179, 237, 0.15)`.
  - Active diagnostic border: `rgba(0, 210, 255, 0.40)`.

## Typography

The type system creates an explicit semantic division:

1. **Executive Body & Hierarchies (`Inter`)**: Tuned for extreme legibility against pitch-dark substrates. Features micro-tightened tracking at large scales to reinforce solidity, and neutral spacing across body tiers. Body copy must never drop below `#94A3B8` (Slate 400) to maintain contrast against `#090D16`.
2. **Telemetry & Execution Traces (`JetBrains Mono`)**: Applied to state readouts, retention scores, dependency indices, progress metrics, and conceptual node tags. Always uppercase when deployed as micro-badges (`telemetry-micro`). Numeric displays leverage tabular figures (`font-variant-numeric: tabular-nums`) to prevent layout shifts during live data re-computations.

## Layout & Spacing

The architecture operates on an adaptive 12-column grid designed for dense split-screen workflows (e.g., adaptive canvas adjacent to telemetry trace sidebars):

- **Desktop (1280px+)**: 12-column system, `margin: 2rem`, `gutter: 1.25rem`. Layout maintains a pinned diagnostic sidebar (320px) with fluid workspace center.
- **Tablet (768px - 1279px)**: 8-column layout, `margin: 1.5rem`, `gutter: 1rem`. Secondary diagnostics collapse into modal trays or bottom drawer surfaces.
- **Mobile (< 768px)**: 4-column layout, `margin: 1rem`, `gutter: 0.75rem`. Stacks modular blocks vertically; telemetry panels convert into horizontal swipeable carousels.

Spacing rhythm follows a strict 4px/8px mathematical cadence. Component padding relies on `space-sm` for dense indicators, `space-md` for interactive controls, and `space-lg` for structural container shells.

## Elevation & Depth

Visual hierarchy uses luminous surface stratification rather than traditional diffuse drop shadows:

- **Surface Stratification**:
  - `Base Canvas`: Flat `#090D16`.
  - `Level 1 (Panels)`: Background `#0D1322` with a 1px perimeter border of `rgba(99, 179, 237, 0.12)`.
  - `Level 2 (Active Cards)`: Background `#131B2E` with `rgba(99, 179, 237, 0.18)` borders and a subtle linear directional highlight across the top edge (`linear-gradient(180deg, rgba(255, 255, 255, 0.04) 0%, transparent 100%)`).
  - `Level 3 (Modal/Command Hub)`: Background `#1A243B` overlaid on backdrop blur `blur(16px)` with outer rim illumination `0 0 24px -4px rgba(0, 210, 255, 0.12)`.
- **Electromagnetic Accent Radiance**:
  - Elements in focus or high-velocity processing states omit default browser rings in favor of a dual-layer inner/outer photoluminescence: `box-shadow: 0 0 0 1px #00D2FF, 0 0 12px rgba(0, 210, 255, 0.35)`.

## Shapes

The design system employs **Level 1 (Soft)** corner geometry. Roundedness is intentionally constrained to evoke industrial engineering and terminal-grade hardware:

- Standard structural panels, cards, and input fields use `0.25rem` (`4px`).
- Floating utility groups, code blocks, and badges use `0.25rem` (`4px`).
- High-level containers and viewport modems scale to `rounded-lg` (`0.5rem` / `8px`).
- Circular pill geometry is strictly forbidden for primary containers, reserved solely for micro status indicator dots (`2px` - `6px`).

## Components

### Buttons
- **Primary (Execute/Commit)**: Background is a linear blend of `#00D2FF` to `#0284C7`. Text is `#090D16` with font `Inter`, weight `600`. Hover emits an ambient cyan halo (`0 0 16px rgba(0, 210, 255, 0.4)`). Active state scales to `0.99`.
- **Secondary (Inspect/Branch)**: Background `#131B2E`, 1px border of `rgba(99, 179, 237, 0.2)`. Text `#E2E8F0`. Hover transitions the border to `#38BDF8` with a dark subtle surface lift to `#1A243B`.
- **Diagnostic Ghost**: Transparent background, `JetBrains Mono` text in `#38BDF8` or `#10B981`, with `rgba(99, 179, 237, 0.15)` border on hover.

### Chips & Micro-Badges
- Scaled for status monitoring: Height `22px`, font `telemetry-micro`, text uppercase.
- **Mastery**: Background `rgba(16, 185, 129, 0.10)`, border `1px solid rgba(52, 211, 153, 0.3)`, text `#34D399`.
- **Hypothesis**: Background `rgba(245, 158, 11, 0.10)`, border `1px solid rgba(245, 158, 11, 0.3)`, text `#FBBF24`.
- **Blocked**: Background `rgba(244, 63, 94, 0.10)`, border `1px solid rgba(244, 63, 94, 0.3)`, text `#FB7185`.

### Input Fields
- Dark recessed background `#0D1322`. 1px border of `rgba(99, 179, 237, 0.18)`. Placeholder text `#475569`.
- On focus: Border transitions to `#00D2FF` accompanied by a localized inner glow (`inset 0 0 6px rgba(0, 210, 255, 0.15)`). Monospaced metadata or hotkey badges sit docked flush right.

### Checkboxes & Radios
- Sharp geometry (`2px` radius for checkboxes; flat-beveled circles for radios).
- Inactive: Surface `#0D1322` with border `rgba(99, 179, 237, 0.25)`.
- Checked: Surface `#00D2FF` or `#10B981`, inner graphic in obsidian `#090D16`. Radiates a faint 4px glow matching the state color.

### Cards & Analytical Nodes
- Base `#0D1322`, border `1px solid rgba(99, 179, 237, 0.15)`. Top edge displays an ultra-subtle light guide (`border-t: 1px solid rgba(255, 255, 255, 0.07)`).
- Padding: strictly `space-md` (internal) and `space-lg` (canvas modules).

### Telemetry Traces (Domain Component)
- Real-time study loop and adaptive logic telemetry monitor.
- Rendered in `#090D16` recessed sub-panels. Typographic readout in `telemetry-md` with alternate lines highlighted via a translucent `#131B2E` striping. Timestamps in `#64748B`, operational symbols in `#00D2FF`.
